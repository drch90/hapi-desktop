# 会话导航与交互优化

本记录覆盖已发布版本和 main 分支的后续改动，区分已实现的交互和后续建议；后续建议尚未实现。安装与升级说明见 [README](../README.md#开始使用)，最新改动见 [未发布更新](release-notes/unreleased.md)。

## main 分支已实现（尚未发布）

- **最近搜索与快速取消**：点击搜索框或箭头显示本机最近 10 条搜索，支持复用、删除和清空；输入时收起列表。Ctrl+K 选中关键词并打开历史，方向键和 Enter 可选择历史条目，Esc 或 × 清空搜索并收起历史，保留机器与未读筛选。
- **暂存入口与保存模式**：有未发送内容时点击“暂存消息”立即保存，旁边的箭头只打开列表。列表打开后，主按钮和原发送快捷键均保存到暂存，关闭后恢复发送。保存失败保留草稿，保存过程中继续修改的内容也保留；归档会话可暂存附件而无需先恢复。
- **暂存跨端共享**：保存成功的文字和附件由 Hub 持久化，并在同一 Hub、账户和会话下与 Web、Android 同步；最近搜索和未提交的草稿仍保存在本机。
- **历史目录排序**：默认按完整路径 A–Z 排列，可在设置中切换为 Z–A 或最近更新，并保留选择；搜索时使用匹配相关度，清空后恢复所选排序。

实现范围和验证记录见 [搜索与暂存优化验证](release-notes/unreleased.md#搜索与暂存优化验证)。

## 1.0.3 已实现

- **桌面用量统计**：解除通用弹窗的 450px 宽度限制，最大宽度调整为 1100px；统计内容随窗口宽度展开，窄窗口中独立滚动，顶部操作保持可见。
- **Codex 继续讨论计划**：按会话保存当前提案的选择。点击后即使没有输入，切换会话或重载也不会重复显示同一提案的按钮；新计划仍提供选择，已有草稿保留，操作不会自动发送消息。
- **发送与草稿保护**：发送使用点击时的正文、附件和定时快照，准备期间的新输入继续保存；恢复到已打开的会话时合并双方草稿，保留各自的发送及队列编辑回执。暂存消息编辑后重新发送，不会用旧回执清理未发送的新内容。
- **工作区与通知恢复**：超过 60 个普通标签或合并双栏后仍能恢复布局；重连全量同步清理已删除会话的待处理计数，并保留同步期间收到的事件。

修复范围和验证结果见 [1.0.3 版本说明](release-notes/v1.0.3.md)。

## 1.0.2 已实现

- **Runner 默认工作区**：新建会话直接展示所选机器配置的工作区，第一项标为默认，支持多个根目录快捷选择和继续浏览子目录。没有明确目录和本机历史时自动使用默认工作区；未配置时仍可手动输入。
- **最近目录与会话目录**：成功创建后按 Hub、账户和机器保留最近 5 个目录，优先恢复上次成功使用的在线机器及目录。快捷列表同时合并 Hub 中同一机器的会话目录和工作树主目录，去重并显示完整路径提示；取消或失败不会改写历史。
- **目录选择与校验**：从工作区分组新建时保留明确的机器和目录；机器信息刷新不会覆盖手动输入或清空的内容，掉线不会自动改用其他机器。已确认不可用或越界的快捷目录会禁用，提交前重新检查目录范围。Windows 盘符和 UNC 路径可正常提交，最近目录随注销清理。

## 1.0.1 已实现

- **状态分层**：列表依次显示“进行中／活跃会话／历史会话”。思考中、待处理和后台任务集中在进行中，在线空闲会话在活跃区，两区按单条会话展示；历史区保留机器和目录大分组。状态变化只移动对应会话。全局置顶独立在最前面，项目置顶在所属状态区内优先显示。
- **筛选与待处理入口**：移除顶部状态分页和“工作区内按状态分区”开关，保留搜索、机器和未读筛选。折叠侧栏中的待处理按钮直接打开并定位会话、聚焦处理区域，必要时清除遮挡的筛选。
- **分组批量操作**：历史工作区标题右键提供“全部展开”“全部折叠”，支持 Shift+F10、方向键、Home/End、Enter 和 Escape。进行中与活跃会话始终独立展示；操作后恢复原输入焦点，不影响正在编辑的草稿。
- **展开规则**：历史目录默认折叠，项目置顶的历史目录默认展开；手动选择按 Hub/账户保存，兼容旧版目录偏好。机器或未读筛选不会改变被隐藏目录的选择，搜索时临时展开匹配目录，清空搜索后恢复。
- **临时预览**：单击历史/归档会话打开本栏唯一的预览标签，再次预览时替换。双击会话行或标签、右键“保留标签页”、开始发送消息、显式恢复或移动标签后保留为普通标签。普通标签不被降级为预览。
- **持久化**：临时预览不随应用重启恢复，也不占用最近关闭记录；草稿、附件和阅读位置仍按会话保存。两栏预览独立，合并时只保留一个预览，普通标签全部保留。
- **归档关闭**：列表菜单和对话顶部归档成功后关闭标签；失败仍可在原处重试。Hub 明确报告会话进入归档状态时也会关闭一次，后续再次打开可正常预览。仅失去在线状态不会触发关闭。
- **双击标签定位**：双击当前标签自动展开侧栏并滚动到会话行；历史会话同时展开所属工作区，临时预览同时保留。被搜索、机器或未读筛选隐藏时清除筛选，仍匹配的筛选保持不变；单击切换、会话引用和通知保持原有侧栏状态。定位活动会话不会改变历史目录的折叠状态，兼容项目置顶、全局置顶与双栏。
- **标签任务状态**：标签显示处理中、待处理、后台任务、空闲、离线或未连接图标，并以独立圆点提示未读。状态优先级与输入框一致，待处理优先于处理中，断线时不把缓存状态显示为正在处理。未读复用会话列表的持久化记录和双栏阅读规则；悬停提供状态、机器和完整路径，支持减少动画设置。

批量展开/折叠作用于当前机器及未读筛选下可见的历史工作区；进行中、活跃和全局置顶区没有目录折叠状态。搜索期间菜单保留可见，但禁用展开/折叠并说明原因。

## 值得优先补充的操作

| 优先级 | 建议                       | 当前情况与使用收益                                                                                                                                                    |
| ------ | -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 高     | 历史预览前进/后退          | 预览替换后需要回到侧栏重新查找上一条。为每栏记录独立访问历史，提供 Alt+Left / Alt+Right 和导航按钮，并恢复各会话阅读位置；导航本身不把预览变成普通标签。              |
| 高     | 搜索结果键盘选择           | 最近搜索已支持 Ctrl+K、方向键和 Enter；匹配到的会话结果仍需单独提供 ↑/↓ 选择、Enter 预览和 Ctrl+Enter 保留，使查找和打开形成完整流程。                                |
| 中     | 会话内全文查找             | 当前会话大纲只搜索用户消息，无法在 AI 回复或代码中查找。增加 Ctrl+F、结果计数和上/下一处，明确搜索范围，较早记录按需加载；大量历史的跨会话全文搜索另需 Hub 接口支持。 |
| 中     | 文件链接定位到行           | 当前带行号链接能打开文件，但不会定位到该行。支持 `file.ts:42` 等格式的行号滚动与高亮，回看 AI 引用的实现位置更直接。                                                  |
| 中     | 后台操作完成时保持当前焦点 | 当前恢复为新会话 ID 时会主动选中返回的标签。若等待期间已切到其他会话，应仅更新原标签及草稿映射，避免完成回调把用户带离当前阅读或输入位置。                            |

下一步建议补预览前进/后退与会话搜索结果的键盘选择。全文查找需要单独处理长会话加载、定位和性能；完整导出、消息分叉/回退等 Web 功能仍见 README 的适配清单。
