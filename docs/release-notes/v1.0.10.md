# HAPI Desktop 1.0.10

本版调整会话标签栏，修复窄栏下的按钮重叠，适用于 Windows 10/11 x64。本次提供本机安装包，公开发布状态以 [GitHub Releases](https://github.com/drch90/hapi-desktop/releases) 为准。

## 升级

1. 从托盘退出正在运行的 HAPI Desktop。
2. 运行 `HAPI-Desktop-1.0.10-win-x64-setup.exe`，使用原安装目录升级；连接设置、标签、草稿和工作区偏好继续保留。

## 本次更新

- 标签随可用宽度自动收窄，长标题显示省略号，标签栏不显示滚动条；空间不足时只露出完整标签，右侧固定的“全部标签”菜单可切换本栏所有已打开会话。
- 列表显示完整标题、机器、路径和当前选中项，适配所属分栏宽度；支持键盘选择、Esc 关闭和焦点恢复。
- 修复切换标签时关闭按钮被裁切、缩放窗口或调整分栏后当前标签移出视野的问题。保留中键关闭、右键操作、预览、拖动排序和跨栏移动。
- 修复窄窗口、大字号下输入框的模型/权限设置与操作按钮重叠，空间不足时自动换行。
- 继续包含 [1.0.9](v1.0.9.md) 的原文显示、问答提交、排队/暂存宽度和 HAPI 对齐修复。

## 历史加载说明

1.0.9 对齐 HAPI 时，切回已缓存会话的最新页从 200 条记录改为 20 条；1.0.10 沿用该策略。记录包含工具调用和状态事件，合并显示后可能只剩少量正文。历史内容仍在 Hub，可点击会话顶部“加载更早的消息”按每页 200 条补载。首次打开原本也只取 20 条；本次对齐额外为仅含工具活动的首次页面尝试补取一页上下文。

## 验证记录

类型检查、生产构建和 19 项模拟 Hub 的 Electron 回归通过，其中新增 3 项覆盖标签收窄、滚动条消除、完整标签与按钮可见性、窗口/分栏缩放、全部标签菜单、焦点及草稿保留，以及七种语言的窄栏按钮布局。既有回归覆盖拖动排序、跨栏移动、中键与批量关闭、预览、未读状态、正文与排队/问答/暂存布局、原文复制和异步问答提交，并确认界面版本为 1.0.10。

七种语言的 354 个本地文案键无缺失。共享协议代码未改变，复用 1.0.9 已通过的相关单元、协议和历史分页验证。

Windows x64 NSIS 安装包及内层压缩包完整性检查通过。包内版本为 1.0.10，180 个构建文件与界面测试所用文件逐一一致；1065 个源码及打包输入未变化，3 个许可/来源文件和 1 个额外资源文件一致。Electron 40.10.6 Windows 运行时与已核实的官方 SHA-256 一致。

构建、测试、打包及验证进程均限制为最多 2 个逻辑 CPU，重型任务串行执行。Electron 验证使用 Linux / Xvfb 和模拟 Hub；未进行 Windows 实机安装测试。
