# HAPI Desktop 1.0.4

本版修复粘贴代码的缩进和 Markdown 解析，加入可展开的输入框，并将聊天长内容和文件预览改为连续浏览；同时汇总 1.0.3 之后的搜索、暂存、目录排序、会话状态和队列修复，适用于 Windows 10/11 x64。公开发布状态以 [GitHub Releases](https://github.com/drch90/hapi-desktop/releases) 为准，main 构建也可从 [Actions](https://github.com/drch90/hapi-desktop/actions/workflows/desktop.yml) 获取。

## 安装与升级

1. 从托盘退出旧版 HAPI Desktop。
2. 运行 `HAPI-Desktop-1.0.4-win-x64-setup.exe`，使用原安装目录升级；已有连接设置、普通标签、草稿和工作区偏好继续保留。
3. Claude 插入和逐轮队列修复还需远端 Hub/runner 包含 [配套补丁](../model-queue-fixes.md#升级范围)；编辑和连续浏览优化随桌面安装包生效。

安装包附带 `SHA256SUMS.txt`。Windows PowerShell 可运行以下命令，与同一构建的校验文件核对：

```powershell
Get-FileHash .\HAPI-Desktop-1.0.4-win-x64-setup.exe -Algorithm SHA256
```

应用没有自动更新，安装包尚未配置代码签名。桌面包不会更新远端 Hub、runner、Web 或 Android 客户端。

## 更新内容

### 消息、编辑与连续浏览

- 修复发送时清除首行缩进的问题，消息原文保留首尾空白；用户正文的缩进按原样显示，粘贴 Nginx 等配置不再误分成 Markdown 代码框，显式围栏仍可生成代码块。
- 输入框自动随内容增高，支持“展开编辑”、双击顶部横条和 Ctrl+Shift+E，保留选区与撤销记录。展开时 Enter 换行、Ctrl+Enter 发送或暂存，Esc 收起，双击正文继续选词。
- 聊天长消息、工具输出、差异和文件预览改为连续滚动，只渲染视口附近的文本；支持全文搜索、跳转行、换行和跳到末尾。聊天输出在末尾时跟随新增内容，翻阅时保留位置；大文件与 Git diff 恢复各自的滚动位置。
- 长内容分享图片改为标明范围的内容节选，避免虚拟滚动的屏外占位生成空白长图；文字复制仍保留全文。大型 Markdown 以源码显示，工具卡片摘要保持简短，打开详情可连续阅读。

### 搜索、暂存与队列

- 会话搜索支持点击输入框或箭头弹出最近搜索，按 Hub/账户在本机保留最近 10 条关键词，忽略大小写去重，支持复用、逐条删除和清空历史。按 Enter、离开搜索区域或取消搜索时记录关键词；输入过程中收起历史列表，方便查看结果。
- 搜索区域内按 Esc 或点击 × 可立即取消搜索，保留机器和未读筛选。Ctrl+K 展开侧栏、选中当前关键词并打开历史；方向键、Home/End 和 Enter 可操作历史条目。
- 点击“暂存消息”立即将当前未发送的文字及附件保存到 Hub；旁边的箭头可只查看列表。列表打开后，主按钮、输入提示及原发送快捷键均切换为保存到暂存，关闭后恢复发送，修复提示说会暂存但实际发给 Agent 的问题。
- 暂存保存失败保留草稿，响应丢失或重载后的重试复用同一个条目 ID；保存期间继续编辑的内容完整保留。归档会话可直接暂存文字及附件，超长文字提示错误并保留全文。
- 明确同步范围：同一 Hub、账户和会话下，保存成功的暂存文字与附件在桌面、Web、Android 共享；搜索历史和未保存的输入框草稿保存在当前客户端。操作说明见 [README](../../README.md#排队消息与暂存消息)。
- 历史会话的目录分组默认按完整路径 A–Z 排序；新增“设置 → 目录分组排序”，可切换路径正序、路径倒序或最近更新，并记住选择。
- 修复 Claude 普通文字“优先插入”因旧模型或权限快照被拒绝、连续插入入口消失的问题；等待原生回执时显示“正在插入”，确认接收后显示“已介入”。
- Claude 和旧 Codex runner 的普通排队消息每轮只处理一条；Codex 等上一轮结束后按已选模型启动后续请求，避免提前发送或合并队列消息。
- 区分等待回执与结果未知，重载不重复发送；会话断开后可继续核对迟到的回执。配套远端补丁、各端更新要求和验证记录见[模型与队列修复](../model-queue-fixes.md)。

### 性能、状态与工程维护

- 修正文档中的补丁占位路径，使用同级仓库下可直接执行的相对路径；补充已应用补丁的只读检查、失败时停止命令组，以及 HAPI 源码验证与构建部署的区别。
- 增加 [PM2 服务更新](../claude-steer.md#pm2-服务更新)说明，包含已核对的启动入口、二进制备份与替换命令、指定服务重启和旧会话的生效条件。
- 固定测试、构建及类型检查的 2 核 CPU 上限，涵盖子进程和远端源码验证，执行方式写入 [仓库指引](../../AGENTS.md)和 [CPU 资源限制](../../README.md#cpu-资源限制)。本机远端部署与 Windows 补丁包记录见[模型与队列修复](../model-queue-fixes.md#本机部署与打包记录)。
- 修复 OpenCode 等会话大量输出和大文件预览时的卡顿：合并连续的 Agent 输出更新并复用未变化的消息；超长内容避免整份解析、高亮和创建节点，通过连续视图浏览并可继续跟随输出，复制保留全文。
- 用户消息回执即时更新，避免批量刷新中的旧快照覆盖优先插入、重试或取消后的最新状态。
- 文件预览不再创建逐字符数组，不把图片解码成文本，关闭预览后释放文件缓存。过大的工具编辑结果分别显示修改前后的原文，避免长时间计算差异。
- 进行中和活跃会话显示与 Web 一致的最近更新时间，时间标签独立按分钟刷新。
- 修复归档时因状态或更新时间变化误增“新动态”标记；保留已有未读状态，并处理归档成功但没有 SSE 推送的情况。
- 修复新建会话时快速修改或清空目录后，Hermes 和 OpenCode 仍可能用旧目录发现模型的竞态。
- 修复 Electron 问答测试受字体回退和滚动像素取整影响的失败：严格检查选项内容完整可见，并验证最后一个选项的点击和提交结果。Actions 失败时保留诊断产物 7 天，原因和复现方法见 [CI 排错记录](../ci-troubleshooting.md)。

详细操作见 [README](../../README.md#对话与输入)和 [Markdown 说明](../markdown.md)。1.0.4 已包含以上桌面改动，旧的 1.0.3 构建需要覆盖安装新版。
