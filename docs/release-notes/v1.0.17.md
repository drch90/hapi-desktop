# HAPI Desktop 1.0.17

本版对齐 Antigravity 原生会话的权限、运行中追加和流式回复，适用于 Windows 10/11 x64。公开发布状态以 [GitHub Releases](https://github.com/drch90/hapi-desktop/releases) 为准。

## 升级

1. 从托盘退出正在运行的 HAPI Desktop。
2. 运行 `HAPI-Desktop-1.0.17-win-x64-setup.exe`，使用原安装目录升级；连接设置、标签、草稿和工作区偏好继续保留。
3. 远端需使用包含 Antigravity 原生终端适配的 HAPI Hub/runner 与 agy 1.5.2+；本机安装包不包含远端部署。

## 本次更新

- 新建与会话设置提供请求确认、Auto、Plan 和始终执行，默认仍为请求确认。成功创建后按 Hub、账户、机器和 CLI 记忆配置；运行时修改失败保留服务端确认值。Auto 取决于 Antigravity 原生账户资格，Plan 用于研究与计划审阅。
- 远端报告原生轮已就绪后，输入框与排队消息显示“优先插入”。普通发送继续排队；追加使用当前轮设置，在工具边界接收。未确认时显示等待状态，送达不明时保留原消息供明确重试或取消；切换与重载不自动重发，也不覆盖新草稿。
- 流式文本按流 ID 替换同一回复，保留原文和模型元数据；思考及工具使用公共消息管线。旧任务日志保留原有显示方式，复制使用完整的最终文本。
- 原生审批沿用工具关联与独立回复 ID，支持允许、本会话允许、拒绝和失败重试；已撤回的旧回复不会取代当前请求。
- 窄窗口、双栏与最大字号下，排队区按剩余高度收缩并保留滚动，避免较长的权限说明把发送／中断按钮挤出窗口。
- 同步 11 个上游源文件和 fixture，记录未提交工作树的准确摘要；补丁刷新与还原保留原始基线，见[对齐记录](../upstream-alignment.md)。

## 验证记录

旧代码的定向用例复现 5 项失败（权限选项、Auto／Plan 记忆与流式原文标识），修复后 93 项桌面单元、729 项共享契约及 362 项共享协议测试通过。类型检查通过。

```sh
bun run typecheck
bun run test --project desktop tests/antigravity.test.tsx tests/new-session-preferences.test.ts tests/agent-settings.test.tsx tests/state.test.ts
bun run test --project hapi-contract
node scripts/limit-cpu.mjs bun run --cwd vendor/hapi/shared test
node scripts/limit-cpu.mjs node scripts/verify-upstream.mjs
```

生产构建及 19 项 Electron 回归通过，覆盖新建与设置失败恢复、原生审批 ID 与三种决策、流式回复/思考/复制、运行中追加、送达不明后的显式重试、新草稿与重载恢复，以及既有 OpenCode、Grok 和排队/问答布局。检查包含 920×640、最大字号、单栏/双栏、深浅主题及法语长文案。

```sh
xvfb-run -a bun run test:e2e tests/antigravity.e2e.ts tests/native-steering.e2e.ts tests/new-session-agents.e2e.ts tests/desktop.e2e.ts tests/alignment.e2e.ts --grep 'Antigravity|agy|opencode|grok uses server|status sections separate individual sessions|queued messages, questions and scratchlist'
xvfb-run -a bun run test:e2e tests/antigravity.e2e.ts --grep 'stream snapshots update one reply'
```

实际界面检查发现首个候选包在窄双栏中仅显示发送按钮的 31.7%；修正队列收缩后重新打包，发送、中断和优先插入的完整可见性、键盘焦点与点击命中均通过。首个候选包及诊断保存在 `build/antigravity-alignment/first-package/`，未作为交付产物。

测试调整也保留了失败证据：审批用例改为校验桌面边界实际返回的 `HTTP_409`，继续验证请求保留、重试和准确的回复 ID/请求体；复制用例等待系统剪贴板写入完成后核对全文。最终构建先通过 18 项 Electron 用例，修正复制等待后定向补跑 1 项通过，其余已通过结果复用。

979 个共享文件、183 个补丁文件均通过基线还原/重放；11 个导入文件与记录的上游工作树 SHA-256 一致。新增权限文案复用已有七种语言的翻译。样式修正没有改变单元/共享协议源码，相关通过结果复用。

所有构建、测试及打包进程树限制到最多 2 个逻辑 CPU，重型任务串行执行。Electron 使用 Linux / Xvfb 与模拟 Hub；未进行 Windows 实机安装或真实 Antigravity 账户验证。
