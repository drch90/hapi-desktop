# 尚未发布的更新

当前源码版本为 1.0.5，改动、升级要求和验证记录已归档到 [1.0.5 版本说明](v1.0.5.md)。公开发布状态以 [GitHub Releases](https://github.com/drch90/hapi-desktop/releases) 为准。

## 定时消息发送

- 输入框新增与 Web 共用的时间选择器，支持 5 分钟、30 分钟、1 小时、4 小时后发送，以及未来 7 天内的指定时间；相对时间从点击发送时计算。
- 定时选择与正文一起保存在本机会话草稿中，兼容旧版绝对时间草稿。发送失败保留实际发送时间，送达不明时检查后重试，沿用原消息 ID。
- 会话列表显示定时消息数量和最近发送时间；提交后的消息沿用 Hub 队列、编辑和取消接口，与 Web 同步。
- 定时消息限制附件与优先插入，正确处理暂存模式、原生命令、会话恢复和取消排队期间的新草稿。过期的草稿时间需重新选择。

无需新增 Hub 接口；需要所连接的 Hub 已支持 Web 的定时消息功能。Hub 需保持运行，CLI 到时在线或之后重连时接收消息。操作说明见 [README：定时发送](../../README.md#定时发送)。

### 验证

在 2 个逻辑 CPU 上限下，类型检查、生产构建和 610 项单元／协议测试通过。使用模拟 Hub 的 16 项 Electron 回归用例通过，覆盖定时时间选择与校验、发送时刻计算、失败及送达不明重试、会话恢复、排队编辑和取消，以及附件、暂存和原生命令。7 种界面的语言目录均无缺失键。
