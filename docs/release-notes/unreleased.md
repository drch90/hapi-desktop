- 用户消息按原文显示，保留缩进、连续空行及 `#` 等 Markdown 字符；复制、重载和放大阅读一致，Agent 回复及文件预览继续使用 Markdown。

## 消息操作栏位置与 Agent 悬停

- 用户消息操作栏完整移到气泡下方，按钮与气泡保持 4px 间隔；保留 28×28px 点击区域，隐藏缓冲调整为 0.5 秒。底部间隔调整为 36px，给按钮及上下留白提供空间，修复 1.0.7 与气泡重叠的问题。
- Agent 消息也加入 0.5 秒隐藏缓冲，重新移入取消隐藏；复制反馈、键盘聚焦和时间显示保持一致，原有操作栏位置与最终回复的常驻淡显继续保留。
- 两类消息都用透明命中区域连通正文与操作栏，在空隙慢移或停留时持续显示，也可直接从下方移入按钮。Agent 正文、工具记录及执行摘要延续紧凑间距。

交互与布局说明见 [文章式对话设计](../design/chat-article.md#消息操作与间距)。

## 消息复制与紧凑间距（1.0.7）

- 用户消息操作栏贴近气泡底边，修复移向复制按钮时经过空隙导致按钮消失的问题；从下方直接移入按钮也可显示操作栏。

## 机器负载与系统健康

- 侧栏机器筛选下加入健康摘要，单台及选中机器直接显示 CPU／内存占用；悬停显示与 Web 共用的负载、健康等级和运行时间，移出后自动关闭，不提供点击展开或固定。
- 多台机器分别展示，支持无会话的在线机器与侧栏折叠状态；Windows 不显示 Unix 的 1 分钟负载。
- 沿用 Hub 机器更新事件，在后续更新或重连时恢复读取；离线、连接中断及读取失败后隐藏缓存指标，未上报时显示“指标不可用”。
- 补齐七种语言，并适配深浅主题、大字号、键盘操作与窄窗口。

无需新增 Hub 接口；需要远端 Hub／runner 支持 Web 的机器健康功能。操作说明见 [README：机器负载与系统健康](../../README.md#机器负载与系统健康)。

## 文章式对话界面

- 按确认后的 Codex 参考稿调整为连续文章排版。用户气泡靠右、随内容收缩，时间和操作栏位于气泡外。
- 普通工具和工具组采用无底色的灰色摘要行，宽度随内容变化；长摘要限制为两行，完整路径与耗时保留在悬停提示和展开详情中。
- 已完成的执行过程可整体折叠，结论、计划和提示继续显示；工具展开时保留阅读位置，支持回到最新消息后继续跟随流式输出。
- 浅色采用白底、灰气泡和蓝色链接，夜间底色为 `#181818`、用户气泡为 `#222222`，保留 Markdown、文件链接、复制、分享、放大阅读与工具组的历史补载。

实现前已保存检查点 `checkpoint/pre-article-chat-20261029`（`4087efc`）。设计说明见 [文章式对话](../design/chat-article.md)。

### 验证

在 2 个逻辑 CPU 上限下，类型检查、生产构建和 33 项相关单元／组件测试通过；937 个共享文件及 50 个补丁文件的来源校验通过。使用模拟 Hub 的 Electron 回归共覆盖 22 项，验证短消息与工具宽度、深浅主题、执行记录折叠、历史补载、工具展开位置、双栏滚动、Markdown、分享、附件、计划与定时发送。最后的图标动画修正重跑 4 项受影响用例，其余结果复用。

普通字号下，“好的”气泡实测 62px，两个工具摘要约 105px 和 152px，正文栏宽 824px；额外检查了 920×640 窗口、双栏和最大字号下的长路径、附件与工具输出。实际截图及宽度记录保存在本机 `build/chat-article/` 下。

## 定时消息发送

- 输入框新增与 Web 共用的时间选择器，支持 5 分钟、30 分钟、1 小时、4 小时后发送，以及未来 7 天内的指定时间；相对时间从点击发送时计算。
- 定时选择与正文一起保存在本机会话草稿中，兼容旧版绝对时间草稿。发送失败保留实际发送时间，送达不明时检查后重试，沿用原消息 ID。
- 会话列表显示定时消息数量和最近发送时间；提交后的消息沿用 Hub 队列、编辑和取消接口，与 Web 同步。
- 定时消息限制附件与优先插入，正确处理暂存模式、原生命令、会话恢复和取消排队期间的新草稿。过期的草稿时间需重新选择。

无需新增 Hub 接口；需要所连接的 Hub 已支持 Web 的定时消息功能。Hub 需保持运行，CLI 到时在线或之后重连时接收消息。操作说明见 [README：定时发送](../../README.md#定时发送)。

### 验证

在 2 个逻辑 CPU 上限下，类型检查、生产构建和 610 项单元／协议测试通过。使用模拟 Hub 的 16 项 Electron 回归用例通过，覆盖定时时间选择与校验、发送时刻计算、失败及送达不明重试、会话恢复、排队编辑和取消，以及附件、暂存和原生命令。7 种界面的语言目录均无缺失键。
