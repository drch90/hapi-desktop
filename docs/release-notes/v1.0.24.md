# HAPI Desktop 1.0.24

本版选择性对齐同级 HAPI v0.36.4，修复新版问答、模型档位与消息提示的桌面兼容行为。来源为 `aa8e6bf8c8d01e380762c2394c5ff709b78a529b`，完整范围见 [上游对齐记录](../upstream-alignment.md#hapi-v0364-兼容对齐)。本次授权为本机打包，没有部署 Hub/runner 或公开发布。

## 用户可见变化

- Hub 任务唤醒显示为“系统消息”，保留完整原文、复制、放大阅读和分享；普通用户消息仍按原文显示。
- Cursor 模型错误与服务端已重发消息的事件不再被隐藏；可展开原始错误文本。桌面不会据此自动重发。
- 问答接受稍后到达的自由输入限制，Cursor/Codex 问题标题更清楚，待回答显示为等待回复。提交按钮可承受翻译工具替换文本节点；提交确认锁、失败答案、草稿和直接显示备注的习惯保持不变。
- DSH 会话设置可选默认、关闭、低、高、最大思考档位；OpenCode 默认项去重。设置失败保留已确认值，旧 Hub 拒绝新能力时仍能继续使用其他设置。
- 共享消息管线保留 Codex 生成统计和 Antigravity 调用次数，兼容新的会话身份与模型错误 metadata；文章式正文、首屏 20 条、历史页 200 条和默认折叠保持不变。

消息入口为 [SystemMessage](../../src/renderer/components/SystemMessage.tsx)、[ModelErrorEvent](../../src/renderer/components/ModelErrorEvent.tsx) 和 [Chat](../../src/renderer/components/Chat.tsx)；档位设置位于 [useSessionSettings](../../src/renderer/components/agent-settings/useSessionSettings.ts)。共享 schema、问答、模型选项和消息管线仍位于 `vendor/hapi/`。未新增依赖或放宽 IPC、认证与文件边界；七种桌面语言同步更新。

通行密钥、额度面板、大附件分块上传、HTML 沙箱预览、原生历史导入、分支/回退、模型错误桥接和自动恢复设置仍需独立桌面接入。当前保留令牌登录、单文件 50 MiB 限制与现有数据隔离；桌面安装包不包含远端升级。

## 升级

轻量覆盖包以已验证的 **1.0.23** 为基础，也兼容此前通过轻量包升级到 1.0.23、仍保留原始可执行程序的安装。解压全部文件，从系统托盘退出 HAPI Desktop 后运行 `update.cmd`，看到 Completed 再重新启动。脚本核对程序与资源摘要，先备份、校验暂存文件，再原子替换；连接、标签、草稿和工作区偏好不参与覆盖。

需要回退时退出客户端，运行同一目录中的 `restore.cmd`，并保留 `resources/app.asar.backup-*`。基础版本或摘要不匹配时，使用完整安装包覆盖原目录。轻量覆盖后应用内显示 1.0.24，Windows 应用列表及 exe 文件属性继续显示基础安装包版本；完整覆盖安装可同步系统登记版本。
