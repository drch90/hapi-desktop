# HAPI Desktop 1.0.2

本版补齐新建会话的 runner 工作区和历史目录选择，适用于 Windows 10/11 x64。

## 主要更新

- **Runner 默认工作区**：新建窗口直接显示所选 runner 配置的工作区，可点击选择多个根目录或继续浏览子目录；没有指定目录和本机历史时，自动填入第一个工作区。
- **历史目录快捷选择**：成功创建后记住该机器最近 5 个目录，重启后优先恢复上次使用的在线机器及目录。快捷列表还包含 Hub 中同一机器已有会话的目录和工作树主目录，首次使用桌面端也可直接选择已有项目。
- **保留选择意图**：从工作区分组新建时，明确指定的机器和目录优先。切换机器后使用对应目录，刷新机器信息不会覆盖手动输入或清空的内容；所选机器离线时禁用创建，不自动改用其他机器。
- **目录检查及路径兼容**：不可用或超出 runner 工作区范围的目录快捷按钮会禁用，提交前重新检查目录范围。移除目录输入框仅允许 Linux 路径的限制，支持 Windows 盘符及 UNC 路径。

最近目录按 Hub、账户和机器保存在本机，取消或创建失败不更新，注销时清理。界面提示已同步到七种语言。详细操作见 [README](https://github.com/drch90/hapi-desktop/blob/v1.0.2/README.md)。

## 安装与升级

1. 从托盘退出旧版 HAPI Desktop。
2. 运行 `HAPI-Desktop-1.0.2-win-x64-setup.exe`，使用原安装目录升级。
3. 已有连接设置、普通标签及草稿继续保留；Hub、runner 和 CLI 需另行部署。

安装包附带 `SHA256SUMS.txt` 校验文件，Windows PowerShell 可运行：

```powershell
Get-FileHash .\HAPI-Desktop-1.0.2-win-x64-setup.exe -Algorithm SHA256
```

安装包尚未配置代码签名，应用目前没有自动更新。项目采用 AGPL-3.0-only，对应源码由版本标签提供。
