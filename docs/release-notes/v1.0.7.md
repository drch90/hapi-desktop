# HAPI Desktop 1.0.7

本版改善用户消息的复制操作，并收紧对话与工具记录之间的留白，适用于 Windows 10/11 x64。本次提供本机安装包，公开发布状态以 [GitHub Releases](https://github.com/drch90/hapi-desktop/releases) 为准。

## 升级

1. 从托盘退出正在运行的 HAPI Desktop。
2. 运行 `HAPI-Desktop-1.0.7-win-x64-setup.exe`，使用原安装目录升级；连接设置、普通标签、草稿和工作区偏好继续保留。
3. 本次交互和间距调整随桌面安装包提供，无需更新 Hub。保留 1.0.6 的机器健康悬浮详情、文章式对话和定时发送；相关远端要求见 [1.0.6 说明](v1.0.6.md)。

## 本次更新

- 用户消息操作栏贴近气泡底边，修复移向复制按钮时意外消失的问题。鼠标移开后保留 1 秒，移回后继续显示；复制反馈和键盘聚焦期间也保持可见。
- 复制、分享和放大阅读按钮的点击范围加大至至少 28×28px，可从下方直接移入操作栏。
- 用户消息间隔从 40px 收为 24px，操作栏复用正常消息间距，显示和隐藏不会挤动正文；普通正文、工具记录及执行摘要的留白同步收紧。
- 保持短气泡随内容收缩，兼容深浅主题、大字号及窄窗口。机器健康详情继续仅悬浮显示。

操作说明见 [文章式阅读](../../README.md#文章式阅读)，设计依据见 [消息操作与间距](../design/chat-article.md#消息操作与间距)。

## 验证记录

在 2 个逻辑 CPU 上限下通过类型检查、生产构建及相关 Electron 回归。旧构建可复现鼠标经过气泡下方时操作栏消失，修复后验证慢移、短暂移开、从下方直接移入、实际坐标点击、键盘复制，以及发送后直接复制原文。

共覆盖 7 项对话回归，检查深浅主题、窄窗口、大字号、短气泡宽度、工具间距、分享图片、历史补载和滚动跟随；最后一次命中范围调整后重跑 4 项受影响用例通过，其余结果复用。

Windows x64 NSIS 打包及安装包完整性检查通过。打包后另有 2 项 Electron 检查通过，确认侧栏和设置显示 1.0.7，机器健康详情仍为悬停显示、移出关闭、点击不固定。

包内版本为 1.0.7；180 个构建文件与上述对话回归和版本检查所用文件逐一一致，另核对了 3 个许可／来源文件及 1 个额外资源文件。1018 个打包输入在构建期间未变化；Electron 40.10.6 Windows 运行时与已核实的官方 SHA-256 一致。

Electron 检查运行于 Linux / Xvfb 和模拟 Hub；未进行 Windows 实机安装测试。健康、定时消息及其他未修改功能沿用 1.0.6 的验证结果。
