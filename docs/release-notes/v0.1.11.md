# HAPI Desktop 0.1.11

首个公开安装包版本，适用于 Windows 10/11 x64。

## 主要功能

- 通过已有 HAPI Hub 管理远端 Codex、Claude Code、OpenCode 和 Hermes 会话。
- 双栏、多标签工作区，支持会话搜索、置顶、未读标记和会话引用。
- 审批与交互问答、排队消息编辑和优先插入、Hub 暂存消息及本地草稿恢复。
- 文件与 Git 变更只读预览、图片和音视频展示、Markdown 分享图片。
- 用户消息保留手动换行，发送、重载和复制后保持多行内容。
- 托盘驻留、系统通知、浅色/深色主题及七种界面语言。

## 下载与使用

1. 下载并运行 `HAPI-Desktop-0.1.11-win-x64-setup.exe`。
2. 输入自己的 Hub 地址和访问令牌。Hub、runner 和 CLI 需另行部署。
3. 打开已有会话，或选择在线机器、工作目录和 CLI 创建会话。

`SHA256SUMS.txt` 提供安装包 SHA-256 校验值。Windows PowerShell 可运行：

```powershell
Get-FileHash .\HAPI-Desktop-0.1.11-win-x64-setup.exe -Algorithm SHA256
```

安装包尚未配置代码签名，Windows 可能显示发布者未知。应用目前没有自动更新，请从 Releases 下载后续版本安装。

完整功能和已知限制见仓库 README。本项目不是官方 HAPI 发行版，采用 AGPL-3.0-only；对应源码可从本 Release 的 Source code 下载。
