# HAPI Desktop 1.0.16

本版对齐 Web 的新建会话选择记忆，并修复首屏自动补载导致切回会话后离开最新消息的问题，适用于 Windows 10/11 x64。公开发布状态以 [GitHub Releases](https://github.com/drch90/hapi-desktop/releases) 为准。

## 升级

1. 从托盘退出正在运行的 HAPI Desktop。
2. 运行 `HAPI-Desktop-1.0.16-win-x64-setup.exe`，使用原安装目录升级；连接设置、标签、草稿和工作区偏好继续保留。

## 本次更新

- 新建窗口记住 CLI 选择；模型、思考强度和权限仅在创建成功后保存，按 Hub、账户、机器和 CLI 分别恢复。取消与失败保留上次成功记录，目录及模型校验完成前不会提交未确认的记忆值，已移除选项回退默认。
- 计划模式、快速模式、Copilot 运行模式和工作树设置仍按次选择，与 Web 一致。目录记录和默认 Codex 行为沿用现有桌面规则。
- 首屏不足一屏时自动补载继续停在最新消息，切回会话及流式回复保持跟随；旧版保存的数字位置已位于底部时恢复跟随。主动上翻、大纲定位和手动补载继续保留阅读位置。
- 移除 GitHub Actions 自动测试，取消普通分支推送及 PR 触发；手动与版本标签仍可检查版本信息、构建 Windows 安装包和发布。

## 验证记录

类型检查、生产构建、30 项单元回归及 31 项 Electron 回归通过，命令、旧版复现和 Hermes 断言调整见[更新记录](unreleased.md)。

升级回归另复现了 1.0.15 已保存的数字底部位置仍处于历史模式；补齐恢复处理后重新打包，旧候选包及诊断保存在 `build/session-preferences-following/first-package/`，未作为本版交付。最终构建另通过 16 项 Electron 检查，覆盖版本显示、选择记忆、旧位置与草稿恢复、首屏补载、切回会话、双栏、大纲和流式跟随：

```sh
xvfb-run -a bun run test:e2e tests/new-session-preferences.e2e.ts tests/transcript-history.e2e.ts
xvfb-run -a bun run test:e2e tests/desktop.e2e.ts --grep 'status sections separate individual sessions|outline loads earlier pages|opening a partial exploration group|outline navigation and live message following|manual scrolling back|layout changes and late image'
```

构建、测试及打包进程树最多使用 2 个逻辑 CPU，重型任务串行执行。Electron 使用 Linux / Xvfb 与模拟 Hub，覆盖 920×640、最大字号、单栏/双栏、深浅主题和法语长文案；未进行 Windows 实机安装验证。

已按顺序运行 `node scripts/limit-cpu.mjs node scripts/verify-package.mjs record-inputs`、`bun run package:win`、`record-output`、上述 Electron 检查及 `verify`。Windows x64 NSIS 安装包和内层压缩包校验通过，包内版本为 1.0.16；180 个构建文件与测试输出逐一一致，1089 个源码及打包输入未变化，3 个许可/来源文件和 1 个额外资源文件一致。Electron 40.10.6 Windows 缓存的 SHA-256 与已保存的官方发布元数据及校验文件一致。
