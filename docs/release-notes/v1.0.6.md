# HAPI Desktop 1.0.6

本版加入与 Web 对齐的机器健康悬浮详情、文章式对话界面和定时消息发送，适用于 Windows 10/11 x64。本次提供本机安装包，公开发布状态以 [GitHub Releases](https://github.com/drch90/hapi-desktop/releases) 为准。

## 升级

1. 从托盘退出正在运行的 HAPI Desktop。
2. 运行 `HAPI-Desktop-1.0.6-win-x64-setup.exe`，使用原安装目录升级；连接设置、普通标签、草稿和工作区偏好继续保留。
3. 机器健康指标和定时发送需要远端 Hub／runner 已支持相应 Web 功能。文章式对话界面随桌面安装包提供；Claude steer 和模型队列的配套要求仍见 [适配说明](../claude-steer.md)。

## 本次更新

- 机器筛选下显示 CPU／内存摘要；悬停展示负载、健康等级及运行时间，移出后关闭，移入详情可继续阅读。去掉点击展开、固定面板和展开箭头；悬停不会抢走输入焦点。
- 健康详情支持多机器、没有会话的在线机器及折叠侧栏。通过 Hub 机器事件自动刷新；离线、重连或读取失败时隐藏旧指标，旧 runner 未上报时显示“指标不可用”。Windows 省略 Unix 的 1 分钟负载。
- 对话改为连续文章排版，用户气泡靠右且随内容收缩；工具使用紧凑的灰色摘要行，已完成的执行过程可折叠，结论与待处理操作继续显示。保留流式跟随、历史补载和展开时的阅读位置。
- 输入框支持相对时间及未来 7 天内的定时发送；计划保存在草稿中，排队后的编辑、取消及定时数量与 Web 同步。需要 Hub 持续运行，CLI 到时在线或之后重连接收消息。
- 适配深浅主题、大字号、窄窗口和七种界面语言。

操作说明见 [机器负载与系统健康](../../README.md#机器负载与系统健康)、[文章式阅读](../../README.md#文章式阅读)及 [定时发送](../../README.md#定时发送)。详细功能验证记录见 [本次更新记录](unreleased.md)。
