# HAPI Desktop 1.0.19

本版精简左侧会话列表，增加可用空间，并将路径复制集中到右键菜单，适用于 Windows 10/11 x64。继续包含 [1.0.18 的 Antigravity 命令与上下文适配](v1.0.18.md)。公开发布状态以 [GitHub Releases](https://github.com/drch90/hapi-desktop/releases) 为准。

## 升级

1. 从托盘退出正在运行的 HAPI Desktop。
2. 运行 `HAPI-Desktop-1.0.19-win-x64-setup.exe`，使用原安装目录升级；连接设置、标签、草稿和工作区偏好继续保留。
3. 侧栏改版无需新增 Hub 接口；Antigravity 的命令、原生上下文和回执兼容仍需配套 HAPI Hub/runner 与 agy 1.5.2+，具体版本见 [1.0.18 升级说明](v1.0.18.md#升级)。

## 本次更新

- 历史工作区只展示目录名、完整路径和数量，移除项目、机器装饰图标和机器名；继续通过顶部筛选框选择机器。
- 复制路径移入工作区右键菜单，成功后显示“已复制”，失败时在菜单内提示并允许重试。搜索期间和机器离线时仍可复制，缺少路径时隐藏入口；标题旁保留新建加号。
- 菜单支持 Shift+F10、方向键、Enter 和 Escape，关闭后恢复焦点；复制不改变分组折叠和搜索状态。
- 会话状态行使用与 Web 一致的 CLI 小图标，悬停及辅助技术可读取名称；顶部品牌与版本收紧为一行。

操作说明见 [会话工作台](../../README.md#会话工作台)。

侧栏功能完成后，`bun run typecheck`、`bun run build`、38 项定向单元／组件测试和 10 项 Electron 回归通过，修改文件的 Prettier 与 diff 空白检查通过。实际界面检查覆盖 920×640、单栏／双栏、220px 侧栏、最大字号、深浅主题及法语长文案；日志和截图位于本机 `build/sidebar-preview/`。

```sh
bun run test --project desktop tests/navigation.test.ts tests/session-search.test.tsx
xvfb-run -a bun run test:e2e tests/sidebar.e2e.ts tests/desktop.e2e.ts --grep 'compact sidebar|workspace copy stays|workspace menus copy|workspace actions handle|workspace group menus|status sections separate|workspace group ordering|live sessions move individually|tab context operations|session search supports'
```

此前 Antigravity 的 114 项桌面单元、738 项共享契约、362 项共享协议及 20 项 Electron 结果复用；验证范围与最终命令回归记录见 [1.0.18](v1.0.18.md#验证记录)。

1.0.19 打包后，对已记录摘要的同一生产构建再次执行 12 项 Electron 检查，全部通过：覆盖上述侧栏行为、界面版本号，以及 Antigravity 命令／别名排队和上下文下降／归零。实际命令：

```sh
xvfb-run -a bun run test:e2e tests/sidebar.e2e.ts tests/desktop.e2e.ts tests/antigravity.e2e.ts --grep 'compact sidebar|workspace copy stays|workspace menus copy|workspace actions handle|workspace group menus|status sections separate|workspace group ordering|live sessions move individually|tab context operations|session search supports|Antigravity commands and aliases|Antigravity context snapshots'

```

输入摘要对比确认，与已验证的 1.0.18 相比仅 `package.json` 版本及三个侧栏源文件改变；Antigravity 与 vendor 来源文件完全一致，因此复用对应测试及 982 个共享文件／186 个补丁文件的还原重放结果。新构建日志、Electron 结果和复用依据位于本机 `build/v1.0.19/`。相关文档的本地链接及 Markdown 锚点检查通过。

所有构建、测试及打包进程树最多使用 2 个逻辑 CPU，重型任务串行执行。Electron 使用 Linux / Xvfb 与模拟 Hub；未进行 Windows 实机安装或真实 Antigravity 账户验证。

## 本机安装包

本版按以下流程记录源码与被测构建，再校验 Windows x64 NSIS 安装包及其内层内容：

```sh
node scripts/limit-cpu.mjs node scripts/verify-package.mjs record-inputs
HAPI_ELECTRON_DIST=build/tool-cache/electron/40.10.6 bun run package:win
node scripts/limit-cpu.mjs node scripts/verify-package.mjs record-output
# 对上一步记录的生产构建执行相关 Electron 回归。
node scripts/limit-cpu.mjs node scripts/verify-package.mjs verify
```

Windows x64 NSIS 与内层压缩包校验通过，包内版本为 **1.0.19**。180 个构建文件与测试输出逐一一致，1099 个源码及打包输入未变化，3 个许可／来源文件与 1 个额外资源一致。Electron 40.10.6 Windows 缓存的 SHA-256 与保存的官方校验文件一致。

安装包：`build/v1.0.19/HAPI-Desktop-1.0.19-win-x64-setup.exe`，大小 **97,968,649 字节**（约 93.4 MiB）。

SHA-256：`8c845bd3edaa9ca026d8ad41d4fefb4ad21b76fa0d2a8791098be98c8c32c37f`。

同目录保存 `SHA256SUMS.txt`、`RELEASE_NOTES.md`、`source-snapshot.json`、`source.patch`、`tested-build-sha256.json`、`verification.json`、复用依据及验证日志。校验时源码为 `8872c4ce16e3209d444652152fe11c2422432ac0` 加本次工作树改动；源码输入摘要与完整补丁可用于复核。
