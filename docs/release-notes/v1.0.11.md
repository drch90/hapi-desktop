# HAPI Desktop 1.0.11

本版修复归档会话被待确认消息锁住、恢复按钮被长草稿挤出屏幕，以及 `/` 开头路径被误判为原生命令的问题，适用于 Windows 10/11 x64。本次提供本机安装包，公开发布状态以 [GitHub Releases](https://github.com/drch90/hapi-desktop/releases) 为准。

## 升级

1. 从托盘退出正在运行的 HAPI Desktop。
2. 运行 `HAPI-Desktop-1.0.11-win-x64-setup.exe`，使用原安装目录升级；连接设置、标签、草稿和工作区偏好继续保留。

## 本次更新

- 待确认消息新增“取消发送”。Hub 确认取消后解除输入锁定，保留正文和附件供修改；若 Agent 已收到，则保留历史，只清理对应的已发送草稿。取消结果仍不明或请求失败时继续保留恢复记录。
- 归档后的“恢复会话”可独立使用，按钮与检查、取消操作集中在提示区，放在长消息预览之前。小窗口和双栏下输入区域可滚动；恢复不会自动重发消息，Hermes 保持原会话 ID。
- 处理送达结果时保护较新草稿、其他待确认记录和切换后的会话，沿用会话恢复时的草稿、附件迁移。
- 按当前命令目录匹配完整命令名。`/root/项目/...`、`/tmp` 等路径和未知的 `/` 开头文本保留“优先插入”，正文按原文提交；已知内置/项目命令与共享会话的 `/clear`、`/new` 保持原生处理。
- 新文案同步七种语言。继续包含 [1.0.10](v1.0.10.md) 的标签栏与窄栏布局修复。

## 验证记录

业务源码与打包前已通过的送达恢复修复一致，复用 108 项定向单元测试、22 项 Electron 回归、类型检查和本地化结果；路径消息修复的既有验证也继续适用。本次重新构建 1.0.11，4 项 Electron 检查通过，覆盖界面及设置中的版本号、路径消息优先插入、Hermes 归档恢复和取消，以及小窗口、双栏下的操作入口。

Windows x64 NSIS 安装包及内层压缩包完整性检查通过。包内版本为 1.0.11，180 个构建文件与桌面测试使用的文件逐一一致；1074 个源码及打包输入未变化，3 个许可/来源文件和 1 个额外资源文件一致。Electron 40.10.6 Windows 运行时与此前已核实的官方 SHA-256 一致。

构建、测试、打包及验证进程均限制为最多 2 个逻辑 CPU，重型任务串行执行。Electron 使用 Linux / Xvfb 和模拟 Hub，未进行 Windows 实机安装或真实 Hermes CLI 验证。
