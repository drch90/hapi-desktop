# HAPI Desktop 1.0.20

修复左侧历史工作区的新建加号错位：会话数量位数变化时，加号始终位于最右侧同一列；目录名、折叠箭头、数量和加号在首行居中对齐，完整路径另起一行。沿用 1.0.19 的右键复制路径、CLI 小图标和 Antigravity 适配。

## 升级

从托盘退出 HAPI Desktop，运行 `HAPI-Desktop-1.0.20-win-x64-setup.exe` 并使用原安装目录升级。连接设置、标签、草稿与工作区偏好继续保留；本次修复无需新增 Hub 接口。

操作说明见 [会话工作台](../../README.md#会话工作台)。

## 验证记录

旧版 1.0.19 在 1／12／100 条会话的工作区中复现加号横向错位 12.72px。修复后，通过类型检查、生产构建和 6 项 Electron 回归；加号在同一列，且与标题、数量及折叠箭头的垂直中心偏差不超过 1px。

```sh
bun run typecheck
bun run build
xvfb-run -a bun run test:e2e tests/sidebar-alignment.e2e.ts tests/sidebar.e2e.ts tests/desktop.e2e.ts --grep 'workspace create buttons|compact sidebar|workspace copy stays|workspace menus copy|workspace actions handle|workspace group menus'
```

实际界面覆盖 220px 侧栏、920×640、单栏／双栏、最大字号、深浅主题和法语长文案，验证点击加号打开正确目录，以及复制、失败重试、缺少路径、离线和折叠菜单。源码未变的其他结果沿用 [1.0.19 验证记录](v1.0.19.md#验证记录)。复现日志、回归结果和界面截图位于本机 `build/sidebar-alignment/`。

1.0.20 打包后在记录摘要的同一构建上通过 7 项 Electron 检查，包含上述 6 项及状态分区／界面版本号回归：

```sh
xvfb-run -a bun run test:e2e tests/sidebar-alignment.e2e.ts tests/sidebar.e2e.ts tests/desktop.e2e.ts --grep 'workspace create buttons|compact sidebar|workspace copy stays|workspace menus copy|workspace actions handle|workspace group menus|status sections separate'
```

最终类型检查、修改文件的 Prettier、版本信息及 diff 检查通过，相关文档的 59 个本地链接和标题锚点有效。输入摘要与 1.0.19 对比仅版本和两个侧栏源文件改变，vendor 来源及纯业务规则均未修改；沿用既有 38 项导航／搜索测试及上游来源校验结果。新包日志与复用依据保存在本机 `build/v1.0.20/`。

构建、测试及打包进程树最多使用 2 个逻辑 CPU，重型任务串行执行。Electron 使用 Linux / Xvfb 和模拟 Hub，未进行 Windows 实机安装验证。

