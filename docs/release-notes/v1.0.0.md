# HAPI Desktop 1.0.0

1.0 正式版，适用于 Windows 10/11 x64，通过已有 HAPI Hub 管理远端 Agent 会话。

## 主要更新

- **工作区分组**：同一机器和目录下的会话统一显示在可折叠的工作区内，再区分进行中、活跃和历史状态。在线但空闲的会话仍属活跃；状态变化不会把会话移出目录。
- **工作区导航**：活跃工作区优先显示，标题包含目录名、路径、机器和会话数量；支持复制完整路径及在该目录新建会话。折叠选择按账户保存，搜索时临时展开匹配的目录。
- **标签页关闭**：支持鼠标中键关闭；右键新增“关闭其他标签页”，保留点中的标签，仅关闭同一栏的其余标签。可用 Ctrl+Shift+T 恢复，原有草稿保留；在另一栏关闭标签时保留当前栏的输入焦点。
- **文件栏目录操作**：文件、文件夹和工作区根目录支持右键复制相对/绝对路径，或将路径引用加入当前会话草稿；支持 Shift+F10 打开菜单。
- **消息与 Markdown**：保留用户消息中的手动换行，补齐常用代码语言和文件名识别、缩进代码块、任务列表、脚注、数学公式及 Mermaid 图表。

## 会话与消息功能

- 双栏多标签工作台，支持拖动排序、跨栏移动、可调整宽度及折叠的会话列表。
- 会话搜索、机器和状态筛选、全局/项目置顶、未读标记，以及输入 `@` 插入会话引用。
- 审批与交互问答、待处理通知及点击定位；输入框状态指示器持续显示处理中、空闲或离线状态。
- 排队消息按“优先插入、编辑、取消”显示图标；Scratchlist 暂存文字和附件并由 Hub 持久化。
- 上下文占用和用量统计、会话大纲、流式回复自动跟随，以及独立保存的双栏草稿和滚动位置。
- 文件与 Git 变更只读预览、图片和音视频展示、Markdown 分享图片，支持浅色/深色主题及七种界面语言。

## 安装与升级

1. 下载并运行 `HAPI-Desktop-1.0.0-win-x64-setup.exe`。旧版本用户先从托盘退出应用，再安装新版。
2. 首次使用时输入自己的 Hub 地址和访问令牌。Hub、runner 和 CLI 需另行部署；新建会话支持 Codex、Claude Code、OpenCode 和 Hermes，可用能力由远端决定。
3. 打开已有会话，或选择在线机器和工作目录创建会话。

安装包附带 `SHA256SUMS.txt` 校验文件。Windows PowerShell 可运行：

```powershell
Get-FileHash .\HAPI-Desktop-1.0.0-win-x64-setup.exe -Algorithm SHA256
```

安装包尚未配置代码签名，Windows 可能显示发布者未知。应用目前没有自动更新，后续版本需下载安装包更新。完整功能和限制见 [README](https://github.com/drch90/hapi-desktop/blob/v1.0.0/README.md)。
