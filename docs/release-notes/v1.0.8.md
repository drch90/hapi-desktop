# HAPI Desktop 1.0.8

本版修复用户消息操作栏与气泡重叠，以及 Agent 消息复制按钮过快消失的问题，适用于 Windows 10/11 x64。本次提供本机安装包，公开发布状态以 [GitHub Releases](https://github.com/drch90/hapi-desktop/releases) 为准。

## 升级

1. 从托盘退出正在运行的 HAPI Desktop。
2. 运行 `HAPI-Desktop-1.0.8-win-x64-setup.exe`，使用原安装目录升级；连接设置、普通标签、草稿和工作区偏好继续保留。
3. 本次修复随桌面安装包提供，无需更新 Hub。此前机器健康悬浮详情和定时发送的远端要求仍见 [1.0.6 说明](v1.0.6.md)。

## 本次更新

- 用户消息操作栏完整放到气泡下方，与气泡相隔 4px；保留较大的点击区域，隐藏缓冲调整为 0.5 秒。消息底部间隔为 36px，按钮和焦点框不再与气泡重叠。
- Agent 消息也使用 0.5 秒隐藏缓冲，移回后继续显示；复制反馈和键盘聚焦期间保持可见。操作栏位置及最终回复的常驻淡显保持原设计。
- 正文与按钮之间的空隙支持连续悬停，慢移或停留不会让操作栏消失；两类消息都可直接从下方移入按钮。
- Agent 正文、工具记录与执行摘要保持紧凑间距，机器健康详情继续仅悬浮显示。

操作说明见 [文章式阅读](../../README.md#文章式阅读)，设计依据见 [消息操作与间距](../design/chat-article.md#消息操作与间距)。

## 验证记录

在 2 个逻辑 CPU 上限下完成类型检查、生产构建及 Windows x64 NSIS 打包。使用 1.0.7 构建复现用户按钮重叠、Agent 中间回复及最终回复过早淡出的问题，新版回归确认两类消息的 0.5 秒缓冲、连续悬停、直接移入、鼠标复制和键盘操作正常。

共覆盖 11 项 Electron 用例，其中 9 项对话回归检查深浅主题、窄窗口、大字号、操作栏与气泡的间距、分享图片、发送原文、历史补载及滚动跟随；另 2 项确认侧栏和设置显示 1.0.8，机器健康详情仍为悬停显示、移出关闭、点击不固定。最后使用同一帧坐标重跑 3 项消息操作用例通过，其余 8 项结果复用。

安装包及内层压缩包完整性检查通过，包内版本为 1.0.8。180 个构建文件与上述界面检查所用文件逐一一致，另核对了 3 个许可／来源文件及 1 个额外资源文件。1018 个打包输入自构建起未变化；Electron 40.10.6 Windows 运行时与已核实的官方 SHA-256 一致。

Electron 检查运行于 Linux / Xvfb 和模拟 Hub；未进行 Windows 实机安装测试。其他未修改功能沿用此前版本的验证结果。
