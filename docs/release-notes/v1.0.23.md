# HAPI Desktop 1.0.23

- 对齐 HAPI v0.34.6 的发送中回执和队列读回；确认前锁定编辑、取消和重试，减少重复发送风险。
- 断线有事件缺口时补齐遗漏消息并刷新原地更新的工具记录，保留已加载历史和分页，防止旧请求覆盖新状态。
- 支持跳过选项问答、忽略非阻塞问答及禁止自由填写；等待远端确认时锁定操作，失败保留答案。修复窄双栏、大字号下取消文案挤出按钮的问题。
- 修正 OpenCode 小写工具名、命令输出和文件读取展示，同步轮次摘要解析；Copilot/Kimi 按当前模型发现思考档位。
- 兼容新的会话任务事件，减少内部子任务重复通知。任务进度条、全文搜索和跨端已读等独立功能尚未接入。

范围、保留行为及来源见 [上游对齐记录](../upstream-alignment.md#hapi-v0346-兼容对齐)。新模型能力和原生消息送达需要配套 Hub/runner，本次只交付桌面客户端。

## 升级

轻量覆盖包以已验证的 **1.0.22** 为基础，包括此前从 1.0.21 轻量升级到 1.0.22 的兼容安装。解压全部文件，从系统托盘退出 HAPI Desktop 后运行 `update.cmd`，看到 Completed 再重新启动。程序与资源摘要不匹配时停止，使用完整安装包覆盖原目录。

脚本先备份旧资源，校验暂存文件后原子替换；连接、标签、草稿和工作区偏好不参与替换。需要回退时退出客户端，运行同一目录中的 `restore.cmd`，并保留 `resources/app.asar.backup-*`。

轻量覆盖后应用内版本为 1.0.23，Windows 应用列表及 exe 文件属性继续显示基础安装包版本。完整覆盖安装可同步系统登记版本。受保护目录需要管理员权限。

正式打包后，同一构建上的 7 项 Electron 检查通过，包含界面与关于窗口的版本号，以及本次新增的发送回执、问答、工具恢复、Copilot/Kimi 档位用例。覆盖升级、恢复、兼容、清理及发布相关的 11 个工程文件与 1.0.22 归档输入逐项一致，复用当时通过的 23 项脚本回归，其中 9 项使用真实 PowerShell 验证升级、重复运行、回退、摘要不符和失败保护，详见 [1.0.22 验证记录](v1.0.22.md#验证记录)。本次另核对了连续轻量升级的基础资源与可执行程序身份。

所有构建和验证按组串行执行，整个进程树限制为 2 CPU。Electron 使用 Linux/Xvfb 和模拟 Hub；复用的覆盖脚本回归使用 Linux PowerShell 7.4.6。未进行 Windows 实机安装或覆盖升级验证。

## 本机安装包

本轮按完整安装包校验后派生轻量包的顺序完成：

```sh
node scripts/limit-cpu.mjs node scripts/verify-package.mjs record-inputs
HAPI_ELECTRON_DIST=build/tool-cache/electron/40.10.6 node scripts/limit-cpu.mjs bun run package:win
node scripts/limit-cpu.mjs node scripts/verify-package.mjs record-output
xvfb-run -a bun run test:e2e tests/upstream-compatibility.e2e.ts tests/desktop.e2e.ts --grep 'new pending|async dismissal|restricted questions|gap recovery|exposes only|status sections separate' --max-failures=1
node scripts/limit-cpu.mjs node scripts/verify-package.mjs verify
bun run package:overlay --from 1.0.22
```

Windows x64 NSIS 与内层压缩包校验通过，包内版本为 **1.0.23**。180 个构建文件与被测输出逐项一致，1118 个源码及打包输入未变化，3 个许可／来源文件和 1 个额外资源一致。Electron 40.10.6 Windows 缓存已重新核对官方 SHA-256。

轻量包取自上述已验证安装包。1.0.22 与 1.0.23 的 Electron 版本、可执行代码、非版本 PE 资源、ASAR 校验策略及 `app.asar` 之外的文件均兼容；ZIP 解包逐项比对通过，资源与被测构建的 180 个文件一致。清单保留了 1.0.21 安装程序的兼容身份，可在此前轻量升至 1.0.22 的安装上继续升级。
