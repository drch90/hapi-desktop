# HAPI Desktop 1.0.1

本版优化工作区分组、历史会话预览和标签导航，适用于 Windows 10/11 x64。

## 主要更新

- **双击标签定位会话**：自动展开会话列表和所属工作区，并滚动到对应会话。若会话被搜索、机器、状态或未读筛选隐藏，会清除筛选后定位；支持双栏、项目置顶和全局置顶，同名目录按机器区分。
- **标签任务状态**：直接显示处理中、待处理及未读指示，同时区分后台任务、空闲、离线和未连接。待处理请求优先显示；未读与会话列表共用本机记录。悬停可查看详细状态、机器和完整目录，动画遵循系统减少动画设置。
- **分组批量展开与折叠**：工作区标题右键新增“全部展开”“全部折叠”，支持键盘操作。包含活动会话的工作区默认展开，即使当前筛选仅显示其中的历史会话；手动折叠选择继续按 Hub/账户保存。
- **历史会话临时预览**：单击历史或归档会话打开当前栏的临时预览，再次预览时替换。双击会话行或标签、右键“保留标签页”、发送消息、恢复或移动后保留为普通标签。两栏预览独立，草稿、附件和阅读位置继续保存；临时预览不随重启恢复，也不占用最近关闭记录。
- **归档后自动关闭标签**：列表菜单或对话顶部归档成功后关闭对应标签，失败时保留以便重试。Hub 明确同步的归档状态同样生效；临时离线不会关闭标签。归档后可再次打开预览。

相关界面提示已同步到全部七种语言。详细操作说明见 [README](https://github.com/drch90/hapi-desktop/blob/v1.0.1/README.md)，后续交互建议见 [交互优化记录](https://github.com/drch90/hapi-desktop/blob/v1.0.1/docs/interaction-review.md)。

## 安装与升级

1. 从托盘退出正在运行的旧版 HAPI Desktop。
2. 下载并运行 `HAPI-Desktop-1.0.1-win-x64-setup.exe`，使用原安装目录升级。
3. 首次使用时输入自己的 Hub 地址和访问令牌；Hub、runner 和 CLI 需另行部署。已有用户的连接设置、普通标签及草稿继续保留。

安装包附带 `SHA256SUMS.txt` 校验文件。Windows PowerShell 可运行：

```powershell
Get-FileHash .\HAPI-Desktop-1.0.1-win-x64-setup.exe -Algorithm SHA256
```

安装包尚未配置代码签名，Windows 可能显示发布者未知。应用目前没有自动更新，后续版本需下载安装包升级。
