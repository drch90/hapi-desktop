# HAPI Desktop 1.0.18

本版补齐 Antigravity 原生命令目录和命令排队保护，并核对原生上下文用量显示，适用于 Windows 10/11 x64。公开发布状态以 [GitHub Releases](https://github.com/drch90/hapi-desktop/releases) 为准。

## 升级

1. 从托盘退出正在运行的 HAPI Desktop。
2. 运行 `HAPI-Desktop-1.0.18-win-x64-setup.exe`，使用原安装目录升级；连接设置、标签、草稿和工作区偏好继续保留。
3. 远端需使用包含 Antigravity 命令与上下文上报的 HAPI Hub/runner（`e0b512cf` 或后续版本）及 agy 1.5.2+；原生回执的换行与首尾空白兼容修复需要 `136c815c`。桌面安装包不包含远端部署。

## 本次更新

- 命令菜单新增 Antigravity 专用目录：帮助、额度、上下文、压缩、清空、状态、模型、思考档位和权限模式。命令发现暂不可用时沿用该目录，避免错误显示 Claude 的 `/doctor`、`/cost` 等命令。
- 已识别的命令和原生别名 `/quota`、`/new`、`/permission` 使用普通发送；输入框和排队区共用判断，不再显示会被 runner 拒绝的“优先插入”。选择补全只修改输入，实际发送保留原文。
- 原生上下文快照沿用共享归一化和现有指示器。新增回归检查用量从正值下降、清空归零、重载恢复与历史保留；状态快照不产生聊天正文，也不计入计费用量。
- 选择性同步本地 HAPI `136c815c` 的 5 个已提交文件，登记来源摘要和可重放补丁；此前权限、审批和流式回复适配继续保留。范围见[对齐记录](../upstream-alignment.md#antigravity-聊天命令与上下文1018)。
