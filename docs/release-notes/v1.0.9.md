# HAPI Desktop 1.0.9

本版修复用户消息格式、排队/问答/暂存界面宽度，以及新版 HAPI 异步问答提交失败的问题，并对齐 HAPI v0.33.5 的相关通信契约，适用于 Windows 10/11 x64。本次提供本机安装包，公开发布状态以 [GitHub Releases](https://github.com/drch90/hapi-desktop/releases) 为准。

## 升级

1. 从托盘退出正在运行的 HAPI Desktop。
2. 运行 `HAPI-Desktop-1.0.9-win-x64-setup.exe`，使用原安装目录升级；连接设置、普通标签、草稿和工作区偏好继续保留。
3. 原文显示、界面宽度及问答 ID 校验的修复由桌面安装包提供。模型发现、异步答案送达和压缩确认仍需配套 Hub/runner；旧 runner 不提供 Claude 模型目录时使用回退选项。

## 本次更新

- 用户消息按原文显示，保留空格、Tab、连续空行、`#` 注释、加粗/列表符号及代码围栏。复制、重载和放大阅读采用相同原文；Agent 回复和文件预览继续使用 Markdown。
- 排队消息、交互问答、暂存列表和输入框适配会话正文宽度。暂存编辑弹窗跟随所属分栏，支持窄窗口和大字号；正文滚动区不会遮挡下方面板的按钮。
- 修复新版 Codex 异步问答 ID 中的嵌套 JSON 转义被路径校验误拦截，导致答案提交返回 `ACTION_FAILED` 的问题。
- 对齐 Codex 原生 Auto 权限、当前会话模型发现、Claude 动态模型目录和思考强度、上下文压缩摘要及队列等待状态、晚到命令结果耗时和首条输入临时标题。

来源、兼容范围和保留的桌面差异见 [HAPI v0.33.5 对齐记录](../upstream-alignment.md)。

## 验证记录

功能改动已通过类型检查、生产构建和 26 项模拟 Hub 的 Electron 回归，覆盖原文与复制、异步问答 IPC、宽屏/双栏/大字号布局、暂存编辑、模型设置、压缩回执和既有发送流程。桌面单元及协议回归覆盖 967 项，其中补齐同步依赖后的 103 项相关用例重跑通过；另有 360 项共享协议测试和 29 项历史分页/子代理定向测试通过。

打包沿用上述功能验证结果，新增 1 项版本回归通过，确认侧栏和设置显示 1.0.9。Windows x64 NSIS 打包、安装包及内层压缩包完整性检查通过，包内版本为 1.0.9；180 个构建文件与版本回归所用文件逐一一致，另核对了 3 个许可/来源文件和 1 个额外资源文件。1065 个源码及打包输入自构建起未变化，Electron 40.10.6 Windows 运行时与已核实的官方 SHA-256 一致。

所有构建、测试与打包进程均限制为最多 2 个逻辑 CPU，重型任务串行执行。Electron 验证使用 Linux / Xvfb 和模拟 Hub；未进行 Windows 实机安装测试。
