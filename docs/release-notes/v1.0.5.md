# HAPI Desktop 1.0.5

本版扩大 Claude 等 Agent 的文字和代码显示区域，加入放大阅读，并恢复长 Markdown 的渲染预览，适用于 Windows 10/11 x64。公开发布状态以 [GitHub Releases](https://github.com/drch90/hapi-desktop/releases) 为准，main 构建也可从 [Actions](https://github.com/drch90/hapi-desktop/actions/workflows/desktop.yml) 获取。

## 升级

1. 从托盘退出正在运行的 HAPI Desktop。
2. 运行 `HAPI-Desktop-1.0.5-win-x64-setup.exe`，使用原安装目录升级；已有连接设置、普通标签、草稿和工作区偏好继续保留。
3. 本次阅读改进随桌面安装包提供；已有 1.0.4 环境无需为这些界面改动更新远端 Hub/runner。Claude steer 和模型队列功能的配套要求仍见 [适配说明](../claude-steer.md)。

Windows PowerShell 可核对安装包 SHA-256：

```powershell
Get-FileHash .\HAPI-Desktop-1.0.5-win-x64-setup.exe -Algorithm SHA256
```

## 输出与长文阅读

- 增大正文和代码字号，减少聊天区留白；代码和长文默认高度随窗口调整，大段内容可拖动底边增高。
- 消息、代码块和文件预览增加“放大阅读”，接近整个窗口大小，也可拖动调整。关闭后返回原入口；源码查找和跳转到行面板优先处理 Esc。
- 长 Markdown 消息提供“预览／源码”切换，默认保留源码连续浏览；放大消息默认渲染。大型 Markdown 文件恢复渲染预览，并继续记住文件模式偏好。
- 长文在后台解析完整文档，按可见范围显示标题、列表、表格、代码、公式和图表。保留跨段引用、列表编号和脚注跳转；长表格连续显示并重复列标题。
- 预览与源码分别保存阅读位置。源码继续支持全文查找、跳转行、换行与复制全文；渲染失败可重试或切回源码。长文分享图片标明“当前内容节选”。
- 修复流式更新期间按钮点击丢失：按住输出控件时暂缓聊天区自动滚动，点击完成后恢复跟随。

详细操作见 [Markdown 使用说明](../markdown.md)及 [交互优化记录](../interaction-review.md)。此前编辑、搜索、暂存、模型与队列修复见 [1.0.4 版本说明](v1.0.4.md)。
