# HAPI Desktop 1.0.12

本版将新建会话列表、模型和权限配置对齐服务端支持的 CLI，适用于 Windows 10/11 x64。本次提供本机安装包，公开发布状态以 [GitHub Releases](https://github.com/drch90/hapi-desktop/releases) 为准。

## 升级

1. 从托盘退出正在运行的 HAPI Desktop。
2. 运行 `HAPI-Desktop-1.0.12-win-x64-setup.exe`，使用原安装目录升级；连接设置、标签、草稿和工作区偏好继续保留。

CLI 检测在所选远端机器执行；Hub、runner 和 CLI 需另行部署或升级，桌面电脑无需安装这些 CLI。

## 本次更新

- 新建列表只显示所选机器检测到的可用 CLI，支持 Antigravity、Claude、Codex、DeepSeek Harness、Copilot、Cursor、Grok Build、Hermes、Kimi、OpenCode 和 Pi。Gemini 继续兼容历史会话，不提供新建入口。
- 切换机器时自动改选可用 CLI；检测中、失败或没有可用项时禁止创建，并提供刷新重试。旧 runner 不支持检测时提示升级。
- 创建与会话设置对齐各 CLI 的模型目录、原生权限及思考档位，补齐 Antigravity、Cursor、Grok、Copilot、Pi 和 Kimi/DeepSeek Harness 的相关能力。切换机器或 CLI 会重置创建配置；依赖目录的模型选择在切换项目时重置。
- Cursor 保留完整模型变体，Pi 按供应商区分同名模型；Copilot 支持运行模式，Codex 会话设置支持快速模式。Pi 和 DeepSeek Harness 的权限由 CLI 管理，Grok 未支持的 Auto 模式不可选。
- 目录查询失败或为空时可使用 CLI 默认配置，并可刷新重试；设置失败保留服务端原值。新文案同步七种语言。
- 继续包含 [1.0.11](v1.0.11.md) 的发送取消与恢复、路径消息优先插入修复，以及此前的机器健康悬浮详情、消息操作栏 0.5 秒隐藏缓冲和紧凑布局。

## 验证记录

业务源码与打包前已完成的 CLI 对齐验证一致，复用类型检查、105 项定向单元/边界测试、19 项 Electron 用例及七种语言 375 个文案键检查。具体命令和覆盖范围见 [CLI 对齐验证记录](unreleased.md#cli-创建与设置对齐1012)。本次通过 `bun run package:win` 重新构建 1.0.12，5 项 Electron 检查通过，覆盖界面及设置中的版本号、切换机器后的可用 CLI、检测失败/旧 runner/空列表与重试、Copilot 和 Pi 的创建及会话设置。

Windows x64 NSIS 安装包及内层压缩包完整性检查通过。包内版本为 1.0.12，180 个构建文件与桌面测试使用的文件逐一一致；1085 个源码及打包输入未变化，3 个许可/来源文件和 1 个额外资源文件一致。Electron 40.10.6 Windows 运行时缓存与官方发布元数据及已记录的 SHA-256 一致。

构建、测试、打包及验证进程均限制为最多 2 个逻辑 CPU，重型任务串行执行。Electron 使用 Linux / Xvfb 和模拟 Hub，未进行 Windows 实机安装或真实 CLI 验证。
