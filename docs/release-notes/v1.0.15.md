# HAPI Desktop 1.0.15

本版对齐 Web 的历史消息滚动补载，适用于 Windows 10/11 x64。接近会话顶部时自动获取更早消息，补载后保持当前阅读位置。本次提供已校验的本机安装包，公开发布状态以 [GitHub Releases](https://github.com/drch90/hapi-desktop/releases) 为准。

## 升级

1. 从托盘退出正在运行的 HAPI Desktop。
2. 运行 `HAPI-Desktop-1.0.15-win-x64-setup.exe`，使用原安装目录升级；连接设置、标签、草稿和工作区偏好继续保留。

## 本次更新

- 向上滚动到距历史顶部约 200 像素时自动补载更早的消息，支持滚轮、键盘和原生滚动条。首屏不足时也会尝试补载一页。
- 首次进入及切回会话仍请求最新 20 条服务端记录，历史每页最多 200 条。每次补载后等待继续上翻，内容重排与滚动位置恢复不会连续拉取历史。
- 补载前以当时可见消息保留阅读位置；离开顶部区域、回到最新消息或切换会话后丢弃迟到的自动请求结果。双栏中的阅读位置和请求独立。
- 保留顶部按钮、大纲和工具组的手动补载；失败时显示错误并允许再次上翻或手动重试。
- 继续包含 [1.0.14](v1.0.14.md) 的 OpenCode 运行中追加、草稿保存及此前的桌面功能。
