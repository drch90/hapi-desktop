## 升级

1.0.21 用户可以解压轻量 ZIP，从托盘退出 HAPI Desktop 后运行 `update.cmd`，成功后重新启动。程序与资源摘要必须匹配；未知或不兼容安装使用 1.0.22 完整安装包覆盖原目录。

脚本先备份旧资源、校验新资源，再原子替换。连接、标签、草稿与工作区偏好继续保留。需要回退时退出客户端，运行同一目录中的 `restore.cmd`；保留 `resources/app.asar.backup-*`。远端 Hub 和 runner 无需更新。

轻量覆盖后应用内版本为 1.0.22，Windows 应用列表和 exe 文件属性仍显示基础安装版本。自定义安装目录可通过文件选择框指定；受保护目录需要管理员权限。
