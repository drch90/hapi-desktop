# 对话与工具卡片样式选版

本页保留第一轮三版方案。根据用户随后提供的 Codex 截图，当前方向已收敛为 [文章式对话](chat-article.md)，预览见 [更新后的交互稿](chat-article.html)。

打开 [交互样式稿](chat-styles.html)，可切换 A／B／C、深色和窄栏，并展开工具、切换输入与输出。页面自包含，可下载后直接用浏览器打开。示例对话及工具结果为演示数据。

## 三种方向

| 方案 | 消息样式 | 工具样式 | 适合的使用方式 |
| --- | --- | --- | --- |
| A · 轻量对话（推荐） | 用户浅灰气泡靠右，Agent 开放正文 | 同轮工具合并为一个细边框面板，内部使用紧凑行 | 长对话、以阅读回复为主 |
| B · 结构卡片 | 用户深色气泡靠右，Agent 开放正文 | 工具独立卡片、路径另起一行、状态胶囊、结果摘要成卡 | 经常查看文件与执行细节 |
| C · 执行轨迹 | 用户淡蓝气泡靠右，Agent 左侧有细线 | 连续执行轨迹、紧凑工具行，展开内容嵌入轨迹 | 工具调用多、经常排查执行过程 |

参考：[OpenUI Intelligent UI](https://www.openui.com/demo/intelligent-ui) 的深色用户气泡、开放正文与细边框内容卡片；ChatGPT Desktop 的简洁对话布局与折叠工具信息。HAPI 的会话侧栏、标签和输入区保留工作台结构。

## 三版共用的规则

### 用户与 Agent 消息

- 用户消息靠右，宽度取决于内容：`inline-size: fit-content; min-inline-size: 0`，仅设置最大宽度。长文本自然换行，代码与附件后续沿用现有的内部滚动和预览能力。
- 用户身份和时间放在气泡外。复制、编辑在悬停或键盘聚焦时显示，操作区不参与气泡宽度计算。
- 演示中的“好的”用于核对短消息：气泡只包含正文与左右内边距。
- Agent 使用独立身份行、开放正文与回复操作区。身份、位置和容器共同区分角色。

### 工具卡片

- 摘要从左到右：工具图标、操作名称、文件／命令摘要、状态、耗时、展开箭头。
- 摘要整行可展开；同一工具只保留一层主展开入口。展开区切换“输出／输入”，复制属于当前输出的操作。
- 路径和命令使用等宽字体，长摘要省略，完整信息放入展开区。完整时间作为次级信息，摘要只保留耗时。
- 已完成使用绿色对勾，执行中使用蓝色状态，失败使用红色错误标记；待用户处理时采用橙色标记和明确操作。状态均有文字，颜色只起辅助作用。
- 示例同时呈现完成、失败和进行中。审批交互、附件、图片、长代码和工具组将随选定方案沿用现有功能。

## 预览检查

- 三种样式均检查短消息宽度、窄栏横向溢出、工具展开和输入／输出切换。
- 支持深色主题，预览无外部脚本、字体或图片依赖。
- 页面渲染与检查通过仓库 `scripts/limit-cpu.mjs` 限制为 2 个逻辑 CPU。

这份提案用于选择视觉方向。正式界面的实现和回归验证在选定后进行。
