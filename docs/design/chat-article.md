# 文章式对话：Codex 参考收敛稿

按用户提供的浅色、深色截图，将前一轮 A／B／C 方案收敛为连续的文章排版，已应用到正式对话界面。实现前的检查点为 `checkpoint/pre-article-chat-20261029`（`4087efc`）。

打开 [交互稿](chat-article.html)，可以切换浅色／深色、窄栏、工具展开和输入／输出；“已完成检查”可收起执行过程，结论继续显示。

## 布局与工具

- 用户消息靠右，浅灰气泡按内容收缩，无最小宽度。时间和操作位于气泡外。
- Agent 正文连续左对齐，以自然段、行内代码、链接和少量加粗组织信息。
- 工具与说明文字交错排列，默认显示小图标、灰色文字和展开箭头。工具行无外框、无填充底色，宽度随文字变化。
- 耗时和文件信息放入悬停提示及展开详情。失败用简短红色文字提示，状态不使用彩色胶囊。
- 工具输出展开后采用自然宽度的代码区；短输出保持紧凑，长输出受可用宽度约束。执行记录可整体折叠，诊断结论保持可见。
- 文件链接使用蓝字，结论与关键短语适量加粗；其他区域使用白灰配色。

正式界面的长工具摘要最多两行，完整路径保留在悬停提示和详情中。工具组沿用历史补载与可缩放详情弹窗。整体折叠只作用于已完成且有结论的执行过程，计划、提示、结论和用户消息保持可见；展开工具时暂停自动跟随以保留阅读位置。

正文、排队、问答、暂存列表和输入框共用 824px 的内容宽度上限及响应式左右留白。暂存编辑弹窗最大 450px，并进一步受所在正文栏宽度限制；双栏时跟随所属会话。用户消息使用原文排版，保留缩进、空行及 Markdown 标记，Agent 正文继续渲染 Markdown。

## 消息操作与间距

用户消息操作栏位于气泡下方，完整按钮区域与气泡相隔 4px。复制、分享和放大阅读按钮的点击区域至少为 28×28px，操作栏下方再留 4px，避免悬停背景和键盘焦点框碰到气泡或下一条消息。短消息仍按正文宽度收缩。

用户与 Agent 消息共用 0.5 秒隐藏缓冲：鼠标移入立即显示操作栏，移出消息和操作栏后开始计时，重新移入取消隐藏。缓冲结束后，Agent 最终回复的操作图标回到常驻淡显、时间隐藏，其他消息的操作栏隐藏。正文与操作栏之间的 4px 空隙用透明命中区域连接，在空隙停留也不会开始隐藏。直接从下方移入按钮同样有效。键盘聚焦、复制成功反馈和复制失败提示期间保持可见；Agent 的时间也随操作栏保留。操作栏绝对定位，显示与隐藏不改变消息高度。

用户消息底部间隔为 36px，完整容纳 28px 按钮与上下各 4px 留白；1.0.7 的 24px 间隔通过上移按钮实现，会与气泡重叠，因此不再使用。Agent 正文间隔继续保持 24px，操作栏位置及最终回复的常驻淡显保持原设计。工具及工具组底部间隔为 8px，执行记录摘要上下内边距为 4px、底部间隔为 8px。最大字号和窄窗口下仍需确保操作栏不遮挡正文及下一条消息。

## 预览检查

检查工具行及用户气泡的内容宽度、长摘要和窄栏溢出、详情切换、过程折叠以及两种主题。页面渲染和检查遵守仓库的 2 个逻辑 CPU 上限。

正式界面实测：“好的”气泡为 62px（28px 文字 + 34px 内边距），工具摘要约为 105px／152px，正文栏为 824px。920×640 窗口的双栏及最大字号检查通过；完整验证记录见 [未发布更新](../release-notes/unreleased.md#文章式对话界面)。

前一轮选版保留在 [三版样式稿](chat-styles.html)，本稿作为正式实现的视觉依据。实际 Electron 界面截图和宽度测量保存在本机 `build/chat-article/` 下。
