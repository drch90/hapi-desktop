# HAPI v0.33.5 对齐记录

本次检查以同级 HAPI 仓库的 `289c2bb1` 为来源，该提交包含上游 v0.33.5（`ba2b5c56`）及本地扩展。桌面改动随 [1.0.9 本机安装包](release-notes/v1.0.9.md)提供。

桌面端采用选择性同步：更新共享协议、聊天归一化与对应 fixtures，并接入现有功能需要的接口和展示逻辑。`UPSTREAM.json` 的原始基线仍为 v0.30.7（`0239edf3`），新来源单独记录为 backport；桌面 IPC、内存消息缓存、文章式工具卡和本地文件操作适配继续由可重放补丁记录。

## 已对齐

| 上游变化 | 桌面处理 |
| --- | --- |
| Codex 异步问答 | 新 ID 包含嵌套 JSON 转义。原有路径校验将其当作非法路径，导致答案到达 Hub 前返回 `ACTION_FAILED`。现在只在明确的问答提交/取消路由中，将规范编码的请求 ID 作为不透明标识处理；其他路由仍校验来源、路径与方法。 |
| Codex 原生 Auto 权限 | 共享权限目录更新为 `default`、`read-only`、`autoReview`、`yolo`，新建与运行时设置沿用同一目录。 |
| Codex 模型发现 | 支持并发客户端的会话优先读取当前 app-server 模型目录；只有 RPC 目标缺失才回退机器发现。 |
| Claude 模型与 effort | 从 runner 读取 CLI 模型目录，保留旧版本分组及当前未列出的模型；发现不可用时回退 Opus、Fable、Sonnet、Haiku。切换到不支持原 effort 的模型时，同一次模型请求清除该 effort；新建表单同步限制。 |
| 上下文压缩 | 展示可用的摘要与实际/估算 token 数，按压缩 ID 合并先后到达的记录。队列识别等待压缩完成的消息，等待期间隐藏重试入口，避免把尚未确认的消息重复提交。 |
| 历史加载 | 切回会话的最新页由 200 条改为 20 条；首次打开仍取 20 条，若只有工具活动则尝试补取一页上下文。点击“加载更早的消息”每次补载 200 条；记录包含工具与事件，合并后可能只显示少量正文。1.0.10 沿用该策略。 |
| 命令结果与子代理 | 同步晚到命令结果的身份、失败状态、原生耗时及缓存统计；缺少开始记录时不伪造开始时间。保留窗口内子代理消息需要的父调用，并补齐无法归属父卡的待处理请求。 |
| 临时标题 | 会话列表、标签和通知使用 Hub 从首条输入生成的 `promptTitle`，正式名称与摘要仍优先。 |

## 本次界面修复

- 用户消息按原文显示，保留空格、Tab、连续空行、反斜杠、`#` 注释、列表符号及代码围栏。可识别链接继续支持跳转；复制和放大阅读使用相同原文。Agent 回复及文件预览保持 Markdown。
- 正文、排队消息、问答、暂存列表和输入框共用文章宽度与左右留白。长路径、长附件名可以换行，窄窗口与双栏按所在会话收缩；暂存编辑弹窗也跟随所属栏。正文滚动区在被下方面板压缩时不会覆盖排队或暂存按钮。

## 保留的桌面差异

跨客户端已读同步、按最后用户输入排序、名称锁定、会话分叉/回退、原生历史导入及 Markdown 本地图片是独立功能接入。本次不替换桌面既有的本机未读记录、状态分组及文件预览规则；它们不阻塞上述通信契约。完整功能差异见 [README](../README.md#尚未适配的-web-功能)。

Hub/runner 负责异步答案送达、压缩确认与模型发现；旧 runner 不提供 Claude 模型目录时仍可使用回退选项。桌面修复需要安装由本次源码构建的客户端，单独更新 Hub 不会替换现有桌面包。

## 验证

所有类型检查、构建及测试均通过 `scripts/limit-cpu.mjs` 限制到最多 2 个逻辑 CPU，重型任务串行执行。结果记录在 [版本说明](release-notes/v1.0.9.md#验证记录)。Electron 使用模拟 Hub，覆盖原文与复制、异步答案的实际 IPC 提交、宽屏/双栏/大字号布局、暂存编辑、模型切换、压缩回执与历史补载。

来源清单记录 973 个共享文件，其中 175 个补丁文件均可还原到原基线并重放；本次来源另记录 138 个 v0.33.5 参考文件。功能验证日志和模拟界面截图保存在本机 `build/upstream-alignment/`，安装包与打包记录保存在 `build/v1.0.9/`。

## 后续会话交互修复（1.0.13）

- OpenCode 会话设置按 Web 行为，将可选的思考档位查询与模型目录解耦。没有档位、查询较慢或暂不可用时，已发现的模型仍可切换；不改变远端接口或模型能力。
- `RequestUserInputFooter` 在提交接口确认接收后保留“已提交、等待 Agent 确认”状态及重复提交锁，直到远端问题状态更新。切换问题或卸载后返回的旧结果不再影响新卡片。此为桌面共享源码的本地适配，不修改同级 HAPI 仓库或原始来源提交。
- 新增共享回归纳入 `hapi-contract`；四个共享文件的当前摘要及 `patches/hapi-desktop.patch` 同步更新，原基线及既有 backport 来源保持原记录。

本轮验证及交付状态见 [1.0.13 版本说明](release-notes/v1.0.13.md)。
